# Отмель

Своя игра на C++ по мотивам сборки TerraFirmaGreg: мир из мелких вокселей (1/16 блока), блочный по сути,
но с постройками, которые ставятся свободно, по вокселю. Скрипты правил - на Lua.

- `docs/решения.md` - дневник решений: почему устроено так, а не иначе. Ничего не делать вопреки ему;
  меняется решение - дописывать новое с датой, старое не стирать.
